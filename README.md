# TransylView 3D — Tururi Virtuale 3D & Digital Twins 8K

Website oficial de prezentare și comenzi pentru **TransylView 3D** — Servicii profesionale de scanare 3D, tururi virtuale imersive (Matterport / 8K Photosphere), planuri 2D cotate și modele secționale Dollhouse 3D în Satu Mare și Transilvania (100 km).

## 🚀 Tehnologii Utilizate
- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** (Design de lux, minimalist, fără iconițe AI generice)
- **Three.js** (Motor 3D WebGL integrat pentru tururi 360°)
- **Framer Motion** (Animații fluide scroll-driven)
- **Lucide Icons**
- **Conformitate ANPC & GDPR România** (SAL, SOL, Politică de Confidențialitate, Politică de Cookie-uri, Termeni și Condiții)

## 📦 Rulare Locală
```bash
# Instalare dependințe
npm install

# Pornire server de dezvoltare
npm run dev

# Rulare build de producție
npm run build
```
